{%- comment -%} The phone version of the photo wall: a few rows under the page content that drift sideways, alternating left and right, the way the wall's columns drift up and down. Photos are dealt round-robin into the rows, cycling through the set until every photo is used and each row's run is at least `run_min` of its own heights wide, comfortably past the widest phone layout. When the set and the row count share a factor, each pass shifts by one photo so rows don't cycle the same few. Each row holds its run twice and drifts by exactly one run, so the loop has no seam. Screen readers get each photo's alt once, on its first appearance. Repeats and the second run are silent. {%- endcomment -%} {%- include wall-set.html wall=include.wall limit=page.wall_limit -%} {%- assign photos = wall_photos -%} {%- assign count = photos.size -%} {%- assign rows = 3 -%} {%- if count < 9 %}{% assign rows = 2 %}{% endif -%} {%- if count < 4 %}{% assign rows = 1 %}{% endif -%} {%- assign step = 0 -%} {%- assign leftover = count | modulo: rows -%} {%- if rows > 1 and leftover == 0 %}{% assign step = 1 %}{% endif -%} {%- assign run_min = 8 -%} {%- assign bound = count | plus: 100 -%}
